# DOOFUS: TILE RUSH 🎮

A fast-paced 3D platform game developed in **Unity 6**, where the player
must continuously move across randomly spawning tiles before they
disappear.

Each tile has a limited lifetime. Reach the newly spawned tile, increase
your score, and keep moving. Fall from the tiles, and it's game over.

## 📌 Game Overview

**DOOFUS: TILE RUSH** is a 3D endless survival/platformer game built in
Unity.

The player starts on a tile while new tiles continuously spawn in random
directions. Each tile remains active only for a limited amount of time
before disappearing with a destruction effect.

### Objective

**Keep moving. Reach the next tile. Survive as long as possible. Get the
highest score.**

## ✨ Features

### 🕹️ Player Controller

-   Smooth character movement
-   Walk animation
-   Run using the **Shift** key
-   Jump using the **Spacebar**
-   Rigidbody-based physics
-   Ground detection
-   Smooth character rotation
-   Idle, Walk, Run, Jump, In-Air, and Falling animations

### 🧱 Dynamic Tile System

-   Random tile generation
-   Tiles spawn in different directions
-   Configurable tile lifetime
-   Countdown timer displayed on each tile
-   Automatic spawning of the next tile
-   Tile appearance/pop-in animation
-   Tile disappearance effect
-   Automatic destruction after the lifetime expires

### 🏆 Score System

-   Score increases when the player reaches a new tile
-   Each tile can only award score once
-   Starting tile does not increase the score
-   Live score displayed during gameplay
-   Final score displayed on the Game Over screen
-   Score resets when restarting the game

### ☠️ Fall & Game Over System

-   Detects when the player falls from the platform
-   Displays the final score
-   Restart button to begin a new game

### 🔊 Audio

-   Main Menu Background sound effect
-   UI button sound effect
-   Game Start sound effect
-   Score Increase sound effect
-   Game Over sound effect

### 🎥 Camera

-   Cinemachine camera setup
-   Smooth gameplay camera following the player

### 🌍 Environment

-   Skybox
-   Directional lighting
-   Shadows

### 🎨 Visual Effects

-   Tile pop-in effect during spawning
-   URP-based vortex/dissolve effect during tile destruction
-   Scene fade transitions

1.  Clone or download this repository.
2.  Open the project using **Unity Hub**.
3.  Open the project with the appropriate **Unity 6** version.
4.  Allow Unity to import all project assets.
5.  Open the Main Menu scene.
6.  Press **Play**.
